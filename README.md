# Profile site

A personal profile site built for the 5COM2002 module. It is written in plain HTML, CSS and JavaScript with no frameworks or libraries, and it is being developed with accessibility (WCAG 2.2 level AA) and usability in mind.

Pages planned:

- About
- Technical interests
- Portfolio
- Project details
- Contact

To view the site locally, open `index.html` in a browser or run `python3 -m http.server 8080` in this folder and go to http://localhost:8080/.
